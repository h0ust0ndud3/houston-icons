# houston-icons
## 🎨 Icon Vault

A tiny, purpose-built repository for hosting **icons, logos, and small UI images**  
— optimized for documentation, dashboards, notes, and homelab projects.

Think of this as my personal **icon CDN** 🚀

---

## 🧭 Whats the Purpose?

This repository exists to:
- Host **small, pre-sized PNG/SVG icons**
- Provide **reliable raw URLs** for embedding
- Avoid broken links, bloated images, and CSS headaches
- Play nicely with tools like:
  - Proxmox Notes
  - README files
  - Dashboards
  - Homelab UIs
  - Docs & wikis

No builds.  
No code.  
Just **icons**.
